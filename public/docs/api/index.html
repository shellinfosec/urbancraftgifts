Urban Craft & Co. API Documentation

RFC 9727 Service Documentation • Base URL: https://urbancraftgifts.com/api

Overview & Agent Discovery

This API provides programmatic access for enterprise clients, partners, and autonomous AI agents to request corporate gifting quotations, explore catalogue metadata, and verify service health.

  • OpenAPI Specification: /.well-known/openapi.json
  • RFC 9727 API Catalog: /.well-known/api-catalog

  • Auth & Agent Registration: /auth.md

Endpoints

POST /api/contact — Submit Corporate Contact Enquiry

Receives corporate inquiry submissions with contact details, company, quantity, optional target date (must not be in the past), and project scope. 

POST /api/contact HTTP/1.1
Host: urbancraftgifts.com
Content-Type: application/json

{
  "name": "Priya Sharma",
  "email": "priya@enterprise.com",
  "phone": "+91 98765 43210",
  "company": "Enterprise Tech India",
  "purpose": "onboarding",
  "quantity": "100–250",
  "date": "2026-12-15",
  "message": "We need custom branded onboarding gift boxes with our logo on the water bottle and leather notebook."
}

POST /api/inquire — Submit Detailed Gift Set Proposal Request

Submits a multi-step structured inquiry including selected category slugs and product SKUs.

GET /api/health — Health Check

Returns server status and Indian Standard Time (IST) heartbeat.
